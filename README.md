# OnlyHttp_Projekt

Aplikacja webowa która implementuje mechanizm autoryzacji oparty o sesję przechowywaną w pliku cookie z flagą HttpOnly.

# Uruchomienie projektu

1. Przejść do katalogu "backend" i zainstalować zależności:
   npm install
2. Urochomić serwer backendowy:
   node app.js
3. Aplikacja będzie dostępna pod adresem:
   http://localhost:3000

Przed uruchomieniem należy zmienić nazwę pliku "db.example.json" na db.json.
